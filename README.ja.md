# PlayerCorpseBlock

![死体で埋め尽くされた地面](docs/corpse-pile.png)

プレイヤーが死亡した場所に死体を残す MOD です。死体は entity ではなく BlockEntity 付きのブロックなので、
死体が大量に積み上がってもチェストが並んでいる程度の負荷で済みます。

## 動作環境

- Minecraft 1.20.1 / Fabric・Forge
- Fabric API（Fabric 版のみ、必須）
- クライアントとサーバーの両方に導入が必要

## プレイヤーの死体（ブロック）

- プレイヤーが死亡した場所に自動で設置されます。クラフトはできません
- 死亡したプレイヤーのスキンを反映した死体が、4 種類のポーズのいずれかで倒れて表示されます
- 1 ブロックに死体 2 体が入ります。1 体目は下半分（ハーフブロック状）、2 体目で 1 ブロック分になります
- 破壊：誰でも壊せます。何もドロップしません
- 右クリックには反応しないので、ブロックや死体をそのまま設置できます
- `renderDistance` より遠い死体は描画されず、`detailDistance` より遠い死体はスキンの外側レイヤーを省略します。
  山の内部に埋まった死体は描画自体を省きます。大量の死体で重いときは、これらの設定を調整してください

## 死体アイテム

- クリエイティブインベントリ（機能ブロック）と、死体のピック（中クリック）で入手できます
- ピック元の死体データを NBT に保持するので、設置すると同じプレイヤーの死体が復元されます
- ハーフブロックのように重なります。死体 1 体のブロックに使うと上半分に入ります
- アイテムの見た目は、実際に保持している死体（スキン込み）で描画されます
- 死体データを持たないアイテムを設置すると、設置した本人の死体になります

## 死亡時の挙動

- アイテムと経験値はバニラどおりドロップします。死体には何も保管されません
- 死体は**やられた場所にそのまま出ます**（空中で死んだ場合も落下せずその場に残ります）
- 同じ場所で死ぬと、そのブロックの上半分 → 1 つ上のブロック、の順に積み上がります
- その列が埋まりきったときだけ、`pileRadius` の範囲で一番近い空き列に移ります
- 死体はプレイヤーが向いていた方向に寝かされ、多少ランダムに回転します
- 生きているプレイヤーや Mob がいるマスには置きません
- 奈落での死亡時は、死体を失わないよう地表に置きます

## 設定

初回起動時に `config/playercorpseblock.properties` が生成されます（クライアントとサーバーで別々です）。

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| `enabled` | `true` | 死亡時に死体を設置する |
| `pileRadius` | `2` | 死亡地点の列が埋まっているときに、死体をずらして探す水平方向の半径 |
| `maxPileHeight` | `24` | 1 列に積み上がる死体ブロックの上限（1 ブロックにつき 2 体） |
| `despawnSeconds` | `0` | 死体が消えるまでの秒数。`0` で消えない |
| `renderDistance` | `32` | クライアント専用。この距離より遠い死体は描画しない |
| `detailDistance` | `16` | クライアント専用。この距離より遠い死体はスキンの外側レイヤーを描画しない |
| `cullHiddenCorpses` | `true` | クライアント専用。6 面すべてが塞がれた死体を描画しない |
